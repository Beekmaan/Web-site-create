# 🔤 Үгийн Сан

Англи үг хайж **дуудлага**, **ижил төстэй үгс**, ахисан үгийн **дунд түвшний орлуулга**-г харах сайт.

## Боломжууд
- 🔊 Дуудлага — IPA, 🇺🇸 / 🇬🇧 аудио, 🐢 удаан горим
- 🔁 Ижил төстэй үгс — түвшингээр (A · B1 · B2 · C1 · C2) өнгөөр ялгагдсан
- 🎯 **Ахисан (C1/C2) үг → дунд түвшний (B1/B2) үгс**
- 🚀 Энгийн үг оруулбал → ахисан түвшний хувилбар
- 📚 504 ахисан үг — монгол утга + IPA (интернэтгүй ч ажиллана), жагсаалтаар шүүж үзэх
- 🇲🇳 Монгол утгаар хайх (жш: «нямбай» → meticulous)
- ✨ Онлайн хувилбарт жагсаалтад байхгүй үгийг Claude-аас асууна
- ⭐ Миний үгс, 🕘 сүүлд хайсан, 🎲 санамсаргүй үг, 🌓 харанхуй горим

## Онлайн хувилбар (claude.ai Artifact)
```bash
node scripts/build-vocab-artifact.js
```
`dist/ugiin-san.html` үүснэ.
