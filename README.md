# 💰 Миний Санхүү

Хувийн орлого, зарлагаа хянах энгийн веб сайт. Сервер, бүртгэл шаардлагагүй — өгөгдөл таны хөтөч (localStorage) дээр хадгалагдана.

## Боломжууд
- ➕ Орлого / зарлага нэмэх, засах, устгах
- 📊 Сарын нийт орлого, зарлага, үлдэгдэл, хэмнэлтийн хувь
- 🎯 Сарын төсөв + явцын мөр (80%-д шар, хэтэрвэл улаан)
- 🍩 Зарлага ангиллаар (donut chart)
- 📈 Сүүлийн 6 сарын орлого vs зарлага (bar chart)
- 🔍 Хайлт, төрлөөр шүүх, сар солих (← → товч)
- ⬇ CSV татах, JSON нөөц хадгалах / сэргээх
- 🌙 Харанхуй горим, 📱 утсанд тохирсон

## Ажиллуулах
`index.html` файлыг хөтөч дээр нээхэд л болно. Эсвэл:

```bash
python3 -m http.server 8000
```

## Бүтэц
```
index.html      — хуудас
css/style.css   — загвар
js/app.js       — логик, график (гадны сангүй)
```
