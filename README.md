# 💰 Миний Санхүү

Хувийн орлого, зарлагаа хянах энгийн веб сайт.

## Боломжууд
- ➕ Орлого / зарлага нэмэх, засах, устгах
- 📊 Сарын нийт орлого, зарлага, үлдэгдэл, хэмнэлтийн хувь
- 🎯 Сарын төсөв + явцын мөр (80%-д шар, хэтэрвэл улаан)
- 🐷 Хуримтлал: зорилго тавих, мөнгө хийх / авах, явц, "сард хэд хийх" тооцоо
- 🏷️ 24 зарлагын ангилал + өөрийн ангилал нэмэх
- 🍩 Зарлага ангиллаар, 📈 сүүлийн 6 сарын орлого vs зарлага
- 🔍 Хайлт, төрлөөр шүүх, сар солих (← → товч)
- ⬇ CSV татах, JSON нөөц хадгалах / сэргээх
- 🧪 Анх нээхэд жишээ өгөгдөл харуулна (хадгалагдахгүй)
- 🌙 Харанхуй горим, 📱 утсанд тохирсон

## Chrome дээр ажиллуулах
**Арга 1 — шууд нээх (хамгийн хялбар)**
1. GitHub дээр **Code → Download ZIP** дарж татаад задлах
2. `index.html` файл дээр баруун товч → **Open with → Google Chrome**
   (эсвэл файлыг Chrome цонх руу чирж оруулах)

**Арга 2 — локал сервер**
```bash
python3 -m http.server 8000
```
Дараа нь Chrome дээр `http://localhost:8000` нээнэ.

> Өгөгдөл тухайн хөтөч (localStorage) дээр хадгалагдана. Өөр компьютер/хөтөч рүү шилжихдээ **Нөөц хадгалах (JSON)** → **Нөөцөөс сэргээх** ашиглана.

## Онлайн хувилбар (claude.ai Artifact)
Нэг файл болгож багцлах:
```bash
node scripts/build-artifact.js
```
`dist/minii-sankhuu.html` үүснэ. Онлайн хувилбарт өгөгдөл хэрэглэгч бүрийн бүртгэлд нууцаар хадгалагдана.

## Бүтэц
```
index.html               — хуудас
css/style.css            — загвар
js/app.js                — логик, график (гадны сангүй)
scripts/build-artifact.js — онлайн хувилбарын нэг файлт багц
```
